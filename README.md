# DevOps

This repository contains a collection of DevOps exercises/projects completed during my studies.

The code itself is not the main focus of this repository.  
The main value lies in the DevOps concepts and workflows applied throughout the exercises, which are not always directly visible in the final code.

## Purpose

The goal of these exercises was to practice:
- Git workflows (branches, merges, pull requests)
- CI/CD pipelines using GitHub Actions
- Code quality tools (ESLint, Prettier)
- Unit testing (Jest)
- Test Driven Development (TDD)
- Collaboration workflows similar to real development teams

## Contents

- Git workflow exercises
- CI/CD with GitHub Actions
- Code quality setups (ESLint / Prettier)
- Unit testing with Jest
- TDD practice exercises
- Branch policies & merge request simulations

## Note

Each folder represents an independent learning exercise and may not be a complete production-ready project.
